Privacy Policy – Kiki's Glam Studio

Last updated: 8 November 2026

Kiki's Glam Studio is a dress-up and hair salon game for children, made by an independent developer in New Zealand. This policy explains what the game does with information.

The short version

The game does not ask for or collect personal information. There are no accounts, no advertising, no in-app purchases, no analytics and no tracking.

What is saved, and where

If a player types their name, and as they play, the game saves the name and the game choices (Kiki's skin tone, hair, makeup, clothes, stickers and sound settings) in the app's storage on that device only, so the game remembers them next time. This information is never sent to the developer or anyone else. It can be deleted at any time in the game under Settings → Clear saved game, or by uninstalling the app.

Other services

The game's files are hosted on GitHub Pages (run by GitHub). When the game downloads or updates, the device connects to GitHub's servers, which can see the device's IP address and may keep standard technical logs under GitHub's own privacy statement. After the first visit the game works offline. The game does not share any information with these services.

Children

The game is designed for children. It does not knowingly collect personal information from children. The "Contact the developer" button is behind a grown-ups-only question so that children ask a parent or carer before sending an email.

Contacting the developer

If you email the developer, your email address and message are used only to reply to you and are not shared.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new date.
